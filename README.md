### 🚀 Highlighted Engineering Projects

#### 1. [Edge ASIC INT8 Neural Network Accelerator](https://github.com/gullhashim1/edgeasic-int8-accelerator)
* **Stack:** `SystemVerilog` | `UVM` | `ASIC Toolchains` | `AXI4`
* **Architecture:** Synthesizable INT8 systolic array accelerator designed for quantized neural network edge inference.
* **Bus Interfacing:** Custom memory management and AXI4-compliant transaction scheduling for low-latency weight streaming.

#### 2. [Automated PIC18F Solder Reflow Controller](https://github.com/abdullah7579/Automated-PIC18F-Driven-Solder-Reflow-Controller)
* **Stack:** `C` | `PIC18F458` | `SPI` | `PWM` | `Python`
* **Sensing & Control:** Closed-loop thermal regulation interfacing a MAX6675 thermocouple over bit-banged SPI.
* **Telemetry:** Hardware PWM heat/fan cycling with real-time serial telemetry streamed to a custom Python monitoring GUI.

#### 3. [Discrete Digital Logic Arcade System](https://github.com/abdullah7579/Whack-A-Mole-Game)
* **Stack:** `Digital Logic` | `555 Timers` | `Counters` | `Hardware Prototyping`
* **Implementation:** Pure RTL-style discrete hardware implementation using synchronous counters, pseudo-random timer triggers, and combinatorial logic matrices without a microcode engine.

#### 4. [RF Transceiver & Discrete Analog Comm Link](https://github.com/abdullah7579/FM-Based-Walkie_Talkie)
* **Stack:** `RF Design` | `LC Tank Tuning` | `Analog Signal Processing`
* **Circuitry:** 75 MHz voice-band communication system featuring discrete transistor-level FM modulators, tuned impedance networks, and low-noise operational demodulation stages.
